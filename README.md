# 聴（Kiku）

iPhone 13 用の音声再生 PWA。Dropbox などから「ファイル」経由で曲を取り込み、選んだ曲を速度を変えて再生する。
アルバム・プレイリストは持たない。

## 構成
- `docs/` … 公開するアプリ本体（GitHub Pages は main ブランチの /docs を配信）
  - `index.html` / `style.css` / `app.js` … 画面と動き
  - `sw.js` … アプリ本体だけをキャッシュ（曲はキャッシュしない）。**部品を変えたら `CACHE` の番号を上げる**
  - `manifest.json`・`icon-*.png`
- `make_icons.py` … アイコン生成（`python C:/Users/asada/ClaudeWk/Kiku/make_icons.py`）

## データの置き場所
- 曲は iPhone のブラウザの IndexedDB（`kiku` → `tracks`＝曲の情報、`blobs`＝音声）
- 速度・並べ替え・自動で次へ の設定は localStorage
- **Safari のタブとホーム画面の「聴」は保存場所が別**。取り込みはホーム画面の「聴」で行う
- **ホーム画面から「聴」を消すと取り込んだ曲も消える**（Dropbox の元ファイルは残る）

## 仕様（試作の時点）
- 取り込み: 音声ファイルだけ選べる・複数選択・同じ名前と大きさの曲は飛ばす
- 並べ替え: ファイル名（数字は数として比べる）・取り込んだ日・ファイルの日付・長さ × 昇順／降順
- 再生: 0.5〜3.0倍（0.05刻み、音程保持）・±10/30秒・シーク・ロック画面（±秒送り）
- 続きから再生: 長さ 10 分以上の曲だけ。再開は 3 秒前から
- 次の曲へ自動で進む（オン／オフ）: 次の曲を先に読み込んでおき、画面消灯中でも進めるようにしている

## 試作で確かめること（iPhone 13 の実機）
1. 200MB 以上の長い音声を取り込めるか・アプリを閉じて開き直しても続きの位置へ飛べるか
2. 「試作の確認用」の persist（保存の固定）と容量
3. 画面を消した後も再生が続くか・ロック画面の操作と進み具合の表示
4. 速度を変えても声の高さが変わらないか・曲を変えても速度が保たれるか
5. 画面を消したまま、次の曲へ自動で進むか
6. 「ファイルの日付」が元の日付になるか（確認用の「ファイルの日付＝取り込んだ時刻の曲」の数）
