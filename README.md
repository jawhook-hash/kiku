# 聴（Kiku）

音声ファイルを選んで、速度を変えて再生する PWA。アルバム・プレイリストは持たない。2つの版がある。

| | iPhone 版 | PC 版 |
|---|---|---|
| URL | https://jawhook-hash.github.io/kiku/ | https://jawhook-hash.github.io/kiku/pc/ |
| 曲の置き場所 | アプリの中に取り込む（Dropbox などから「ファイル」経由） | PC のフォルダのまま（コピーしない） |
| 分け方 | グループ（自分で名前を付ける） | 登録したフォルダ |
| ブラウザ | Safari（ホーム画面に追加） | Edge・Chrome（アプリとしてインストール） |

## 構成
- `docs/` … 公開するアプリ本体（GitHub Pages は main ブランチの /docs を配信）
  - `player.js` … **両方の版が使う部品**（再生欄・速度・続きから再生・次へ・区間リピート・ロック画面／メディアキー・キーボード、表示の小道具）。
    再生欄の HTML もここで組み立てる。曲の置き場所の違いは `createPlayer` に渡す `loadUrl` が隠す
  - `index.html` / `app.js` … iPhone 版（取り込み・グループ・選ぶモード）
  - `pc/index.html` / `pc/pc.js` / `pc/manifest.json` … PC 版（フォルダ登録・読む許可・一覧）
  - `style.css` … 両方の見た目（広い画面では幅 760px で中央寄せ）
  - `sw.js` … アプリ本体だけをキャッシュ（曲はキャッシュしない）。**部品を変えたら `CACHE` の番号を上げる**
  - `manifest.json`・`icon-*.png`
- `make_icons.py` … アイコン生成（`python C:/Users/asada/ClaudeWk/Kiku/make_icons.py`）

## データの置き場所
- iPhone 版: 曲は IndexedDB `kiku`（`tracks`＝曲の情報、`blobs`＝音声）、設定は localStorage `kiku-settings`
  - **Safari のタブとホーム画面の「聴」は保存場所が別**。取り込みはホーム画面の「聴」で行う
  - **ホーム画面から「聴」を消すと取り込んだ曲も消える**（Dropbox の元ファイルは残る）
- PC 版: IndexedDB `kiku-pc`（`folders`＝登録したフォルダの鍵、`meta`＝曲ごとの長さ・続きの位置。
  キーは「フォルダID/中の道筋/ファイル名」）、設定は localStorage `kiku-pc-settings`
  - 同じ URL の家（jawhook-hash.github.io）なので、iPhone 版と名前を分けている

## 共通の仕様（player.js）
- 再生: 0.5〜3.0倍（0.05刻み、音程保持）・±10/30秒・シーク・ロック画面／メディアキー（±秒送り）
- 続きから再生: 長さ 10 分以上の曲だけ。再開は 3 秒前から
- 次の曲へ自動で進む（オン／オフ）: 一覧の並び順。次の曲を先に読み込んでおき、画面消灯中でも進める
- 区間リピート: A・B を押した位置の間を繰り返す（timeupdate で判定するのでズレは 0.25 秒ほど）。曲を変えると解除
- キーボード: スペース＝再生/停止、←→＝10秒（Shift で30秒）、↑↓＝速度±0.05、A・B＝区間、Esc＝区間を解除

## iPhone 版の仕様
- 取り込み: 音声ファイルだけ選べる・複数選択・同じ名前と大きさの曲は飛ばす
- グループ: 「すべて」表示中に取り込むとグループ名を聞く（空欄＝未分類）。絞り込み中はそのグループへ入る。
  曲の「…」→「グループを変える／削除」。グループがひとつもない間は選択欄を隠す
- 選ぶモード: 「選ぶ」→ 曲をタップしてチェック → 「グループへ」「削除」でまとめて処理。
  「すべて選択」は表示中の曲だけが対象。絞り込みで見えなくなった曲は選択から外す
- 並べ替え: ファイル名（数字は数として比べる）・取り込んだ日・ファイルの日付・長さ × 昇順／降順
- 下の「情報」: ホーム画面起動か・保存の固定・容量など

## PC 版の仕様
- 「フォルダを追加」で選んだフォルダの音声（mp3・m4a・m4b・aac・wav・flac・ogg・opus・webm）を、サブフォルダも含めて一覧にする
- **PC のファイルは読むだけ**。「登録を外す」も一覧から外すだけで、フォルダとファイルは残る
- 起動のたびにブラウザが読む許可を求めることがある → 上に出る「読む許可を出す」を押す
- ファイルを足した・消したときは「再読み込み」。大きさか日付が変わったファイルは長さと続きの位置を測り直す
- 長さは一覧を出した後に1曲ずつ調べて覚える（2回目からはすぐ出る）
- 並べ替え: ファイル名（サブフォルダの道筋込み）・ファイルの日付・長さ × 昇順／降順
- フォルダが2つ以上あると、上の選択欄でフォルダを切り替えられる

## 確かめ方
自動テストは本物のフォルダ選択画面を押せないので、ブラウザ内の保存領域（OPFS）にフォルダを作り、
`addFolderHandle()` に渡して試す（OPFS のフォルダも同じ種類の鍵）。
